# MistVault Explorer

MistVault Explorer는 개인 서버용 프리미엄 파일 관리 웹 인터페이스입니다. Go 백엔드와 모던한 바닐라 JS/CSS 프론트엔드로 구성되어 있으며, 데스크탑 급의 파일 관리 경험을 제공합니다.

## ✨ 주요 기능

### 1. 지능형 파일 관리
- **다중 선택 및 일괄 작업**: 파일 체크박스를 통해 여러 항목을 선택하고 한 번에 복사, 이동, 삭제가 가능합니다.
- **폴더 용량 계산**: 폴더 내 모든 파일의 크기를 합산하여 실제 사용량을 정확하게 표시합니다.
- **직관적인 클릭 시스템**: 
  - 파일/폴더 이름 1회 클릭 시 즉시 탐색/열기.
  - 이름 외 영역 클릭 시 행 선택, 더블 클릭 시 진입.
  - 이름 부분 텍스트 드래그 방지로 오작동 방지.

### 2. 고급 업로드 관리자 (Upload Manager)
- **실시간 진행률**: 파일별 진행바, 퍼센트, 업로드 속도 기반 남은 시간(ETA) 표시.
- **작업 제어**: 업로드 중 개별 취소 기능 제공.
- **이력 관리**: 업로드 완료 후에도 목록이 유지되며, 사용자가 확인 후 'Clear' 버튼으로 수동 삭제 가능.

### 3. 실시간 시스템 모니터링
- **스토리지 대시보드**: 사이드바 하단에서 연결된 모든 드라이브의 용량 상태를 게이지 바와 함께 실시간 확인.
- **네트워크 지연시간(Ping)**: 헤더에서 서버와의 응답 속도를 ms 단위로 실시간 모니터링.

### 4. 향상된 주소창 (Breadcrumb)
- **반응형 내비게이션**: 폴더 경로 클릭 시 즉시 이동. 경로가 길어지면 왼쪽부터 부드럽게 생략 처리(Fade-out).
- **직접 입력 모드**: 연필 아이콘을 클릭하여 경로를 직접 입력하거나 복사할 수 있으며, 버튼 토글로 모드 전환 가능.

### 5. 사용자 경험 및 테마
- **다크 모드 지원**: 시스템 설정 연동 및 수동 전환 가능한 프리미엄 다크/라이트 테마.
- **반응형 레이아웃**: 모바일과 데스크탑 환경에 최적화된 사이드바 및 콘텐츠 영역.
- **미디어 프리뷰**: 이미지, 동영상(.ts 포함), 오디오, 텍스트 파일의 즉시 미리보기 및 편집 지원.

## 🚀 시작하기

### 실행 방법
```bash
go run main.go
```
기본적으로 `http://localhost:8097`에서 접속 가능합니다.

### 설정
- `mistvault_settings.json` 파일을 통해 즐겨찾기 및 테마 설정이 서버에 영구 저장됩니다.
- `/Volumes` 디렉토리를 기본 루트로 탐색하며, 필요 시 `main.go`의 `rootDir` 상수를 수정하여 변경할 수 있습니다.
